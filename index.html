RESUMEN RÁPIDO

Tres verbos para describir

CARACTERÍSTICAS

SER + adjetivo

Lucía es alta, delgada y pelirroja.

Use para características gerais.
TRAÇOS FÍSICOS

TENER + sustantivo

Lucía tiene el pelo largo y rizado.

Use para cabelo, olhos, barba e outros traços.
ROUPAS E ACESSÓRIOS

LLEVAR + ropa

Lucía lleva un vestido verde.

Use para dizer o que alguém está usando.
