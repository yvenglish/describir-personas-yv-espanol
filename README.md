# Describir personas — YV Español

Página estática e responsiva para uma revisão de espanhol A1–A2 sobre aparência física, roupas e acessórios. Inclui resumo, galeria, áudio, autocorreção e produção escrita.

## Publicar no GitHub Pages

1. Descompacte o projeto.
2. Envie `index.html`, `styles.css`, `script.js` e a pasta `assets` para a raiz do repositório.
3. Em **Settings → Pages**, publique a branch principal pela pasta raiz.

O áudio usa a síntese de voz do navegador com preferência por `es-ES`. A voz disponível pode variar conforme o dispositivo.
